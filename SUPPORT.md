# Support

SYSCORA 0.1.x is a developer preview with best-effort community support and no
service-level agreement.

- Bugs and feature requests: use this repository's GitHub Issues.
- Vulnerabilities: follow `SECURITY.md` and use a private GitHub security
  advisory. Never file them publicly.
- Include the SYSCORA version, Windows version and edition, exact reproduction
  steps, expected and observed behavior, and sanitized logs.

Remove API keys, OAuth tokens, personal data, private file contents, and other
people's information before sharing diagnostics. Support for a consumer launch
requires an owned domain, staffed contact route, incident process, published
response targets, and account/billing support.
